# Review notes — one inventory, three formats

Fill the inventory once, then paste the version for each store. Never put real user credentials here; create a dedicated demo account that stays valid (no SMS/2FA) for at least two weeks after submission.

## Inventory

- App purpose (1 sentence):
- How to reach core features without login (guest/Skip?):
- Demo account (if login is required): username / password
- Where account deletion is: (e.g. Account → Delete account)
- Payments: none / IAP products / subscriptions
- External services (AI APIs, payments, maps…):
- Regional differences:
- Anything a reviewer might misread (e.g. "PRO" wording, content generated by user, links out):

---

## Apple — App Review Information → Notes (≤ 4000 chars)

```text
PURPOSE
<App> helps users <do X>. <Free / how it makes money>.

ACCESS
- No account needed: tap "<Skip>" on the first screen to use all features.
- Optional sign-in (email / Sign in with Apple) in the <Account> tab.
- Demo account (if needed): <user> / <password>

ACCOUNT DELETION
<Account> → <Delete account> → confirm. Deletes the account and its data immediately.

PURCHASES
<The app has no in-app purchases; all features are free.> / <IAP products: …; Restore in Settings.>

EXTERNAL SERVICES
<e.g. The app does not run AI models; it builds text the user can copy into apps they choose.>

CONTACT
<name>, <email>, <phone>
```

## Google Play — App content → App access

- Choose "All or some functionality is restricted" only if login is required.
- Instructions (keep short): `Tap "Skip" on the first screen to use the app as a guest. To test sign-in use <user>/<password>. Account deletion: Account > Delete account.`

## Huawei AppGallery — Review information → "For reviewer" (≤ 300 chars)

Count characters before saving (over 300 → "Invalid parameter"). Example (274 chars):

```text
Free <category> app. No account needed: tap Skip or continue as guest. Optional email sign-up in Account tab; delete account: Account > Delete account. No purchases, ads or GMS dependency. <One line on what the app does / doesn't do.>
```

Quick count: `python3 -c "import sys;print(len(sys.stdin.read().strip()))" < notes.txt`
